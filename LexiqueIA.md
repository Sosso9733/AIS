#**Lexique IA**

-**Inférence** : Processus par lequel un modèle IA génère une réponse à partir de ce qu'il a appris.

-**RAG (Retrieval-Augmented Generation)** : Technique combinant recherche d'informations externes et génération de texte par une IA. Notamment en lui apportant des fichiers.

-**ChatBot** : Programme conversationnel simulant un dialogue avec un humain.

-**Paramètre** : Valeur interne ajustée pendant l'entraînement d'un modèle pour qu'il apprenne.

-**DataSet** : Ensemble de données utilisé pour entraîner ou tester un modèle IA.

-**Agent IA** : Système autonome capable de percevoir, décider et agir pour atteindre un objectif.

-**Modèle** : Représentation mathématique entraînée pour effectuer une tâche (prédiction, génération, etc.).

-**Réseau de Neurones** : Architecture informatique inspirée du cerveau, composée de couches de nœuds interconnectés.

-**Machine Learning** : Discipline permettant à une machine d'apprendre à partir de données sans être explicitement programmée.

-**NLP (Natural Language Processing)** : Traitement automatique du langage naturel par une machine.

-**Qwen** : Famille de grands modèles de langage développés par Alibaba.

-**Deep Learning** : Sous-domaine du Machine Learning utilisant des réseaux de neurones profonds (à plusieurs couches).

-**GPT (Generative Pre-trained Transformer)** : Famille de modèles de langage génératifs développés par OpenAI.

-**IA Adaptative** : IA capable d'ajuster son comportement en fonction de nouvelles données ou situations.

-**IA Générale (AGI)** : IA hypothétique capable d'égaler l'intelligence humaine dans toutes les tâches cognitives.

-**Ollama** : Outil permettant d'exécuter des LLM localement sur sa machine.

-**IA Générative** : IA capable de créer du contenu original (texte, image, son...).

-**Singularité Technologique** : Moment hypothétique où l'IA dépasserait l'intelligence humaine, changeant radicalement la société.

-**LLM** (Large Language Model) : Modèle de langage de grande taille entraîné sur d'immenses corpus de texte.

-**Hallucination** : Réponse générée par une IA qui semble plausible mais est fausse ou inventée.

-**Embedding** : Représentation vectorielle numérique d'un mot, phrase ou donnée, capturant son sens.

-**Token** : Unité de texte (mot, sous-mot ou caractère) traitée par un modèle de langage.

-**European AI Act** : Règlement européen encadrant le développement et l'usage de l'intelligence artificielle.

-**Prompt** : Instruction ou question donnée à une IA pour obtenir une réponse.

-**Algorithme** : Suite d'instructions permettant de résoudre un problème ou d'effectuer une tâche.

-**Test de Turing** : Test évaluant si une machine peut imiter une conversation humaine de façon indiscernable.

-**Big Data** : Ensembles de données massifs et complexes nécessitant des outils spécifiques pour être traités.

-**Biais** : Distorsion systématique dans les résultats d'une IA, souvent héritée des données d'entraînement.

-**ModelFile** : Fichier de configuration définissant les paramètres d'un modèle (utilisé notamment avec Ollama).

-**SystemPrompt** : Instruction initiale définissant le comportement général et le rôle d'une IA avant l'interaction utilisateur.

-**Données** : Informations brutes (texte, image, chiffres...) servant de base à l'entraînement ou au fonctionnement d'une IA.
